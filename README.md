# 🧠 AI Mock Interview Platform

This project helps candidates prepare and practice for upcoming interviews.
Users can upload their resume and job description, start a mock interview, and receive a detailed performance report at the end.

---

## 🛠️ Tech Stack

- Python `>= 3.9`
- Streamlit
- Open AI for LLMs

---

## ⚙️ Project Setup

### Create and Activate Virtual Environment

```bash
python3 -m venv venv
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Streamlit Applications

```bash
streamlit run src/Main.py
```

### Open Browser

```bash
 Local URL: http://localhost:8501
```
